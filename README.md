# Умная IoT-подставка для горячих напитков (Smart Coaster IoT)

Учебный IoT-проект для контроля температуры горячих напитков и автоматического уведомления пользователя о достижении идеальной температуры для питья. Проект реализуется на базе микроконтроллера с Wi-Fi (ESP8266/ESP32) и облачных уведомлений.

## Актуальность

Многие люди наливают себе горячий чай или кофе, садятся за работу за компьютер и забывают про напиток. В итоге он полностью остывает и становится невкусным. Использование обычной кружки не позволяет узнать текущую температуру без пробы, а постоянно отвлекаться на проверку — неудобно.

## Решение

Автономное IoT-устройство в виде подставки для кружки. Оно автоматически определяет наличие кружки, бесконтактно измеряет температуру жидкости и присылает уведомление (например, в Telegram), когда напиток остыл до идеальной для употребления температуры (например, 60°C).

## Функционал проекта

1. **Мониторинг наличия кружки:** Тензодатчик непрерывно измеряет вес. Это позволяет системе понимать, стоит ли кружка на подставке и есть ли в ней жидкость (чтобы не измерять температуру воздуха).
2. **Бесконтактное измерение температуры:** Инфракрасный датчик направлен на стенку/дно кружки и считывает температуру без погружения в воду.
3. **Облачные уведомления:** Когда напиток достигает заданного диапазона (например, 55-60°C), микроконтроллер отправляет сигнал в интернет, и пользователю приходит push-уведомление или сообщение.
4. **Визуализация (опционально):** Вывод текущего статуса («Слишком горячо», «Можно пить», «Кружка пуста») на небольшой дисплей.

## Аппаратное обеспечение

Проект реализуется на макетной плате.

* **Микроконтроллер:** NodeMCU ESP8266 (или ESP32 со встроенным Wi-Fi модулем)
* **Датчик веса:** Тензодатчик + модуль АЦП HX711 (для определения наличия полной кружки)
* **Датчик температуры:** Инфракрасный бесконтактный датчик MLX90614
* **Исполнительное устройство:** OLED-дисплей 0.96" (I2C) для вывода температуры / Зуммер для звукового сигнала

## Программное обеспечение и сервисы

* **Среда разработки:** Arduino IDE
* **Облачный сервис:** Telegram Bot API (или Blynk / ThingSpeak) — для отправки уведомлений на смартфон о готовности напитка.

## Алгоритм работы системы

1. При включении устройство подключается к заданной Wi-Fi сети.
2. Происходит тарирование (сброс в ноль) тензодатчика.
3. В основном цикле микроконтроллер считывает показания веса (HX711).
4. Проверяются условия запуска:
   * Если `Вес < Порога` (кружки нет или она пустая) — система находится в спящем режиме.
   * Если `Вес > Порога` — система понимает, что поставили полный напиток, и активирует датчик температуры.
5. Инфракрасный датчик (MLX90614) начинает считывать температуру жидкости:
   * Если `Температура > 60°C` — напиток остывает, статус на дисплее «Осторожно, горячо!».
   * Если `Температура опустилась до 60°C` — формируется HTTP-запрос, и пользователю отправляется уведомление в Telegram («Ваш напиток идеальной температуры, пора пить!»). Включается звуковой сигнал.
6. Как только пользователь поднимает кружку (вес падает), цикл завершается, и устройство снова переходит в режим ожидания.
